## 🚀 Deployment Options

### Option 1: Spring Boot Static Resources (Recommended)

```bash
# Copy to your Spring Boot project
cp -r build/web/* /path/to/spring-boot-project/src/main/resources/static/app/

# The app will be available at:
# https://jprime.io/app/
```

### Option 2: Separate Web Server

```bash
# Deploy to nginx/apache
scp -r build/web/* user@server:/var/www/jprime-pwa/

# Configure web server to serve from /app or /mobile
```

### Option 3: CDN Deployment

Upload `build/web/*` to:
- AWS S3 + CloudFront
- Google Cloud Storage
- Netlify
- Vercel

## 🆘 Troubleshooting

**Install prompt not showing?**
- Must be served over HTTPS
- User can manually install from browser menu
- Check browser DevTools → Application → Manifest

**Sessions not loading?**
- Verify API endpoint is accessible
- Check CORS headers
- Verify network connectivity

**App not updating?**
- Service worker caches aggressively
- Force refresh: Ctrl+Shift+R (Cmd+Shift+R on Mac)
- Or clear browser cache
