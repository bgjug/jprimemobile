## 🚀 How to Deploy

### Option 1: Copy to Your Spring Boot Static Resources

Copy the entire `build/web` contents to your Spring Boot project:

```bash
# From your jprimemobile directory
cp -r build/web/* /path/to/your/spring-boot-project/src/main/resources/static/pwa/
```

Then in your Spring Boot app, the PWA will be available at:
```
https://jprime.io/pwa/
```

### Option 2: Serve from a Separate Nginx/Apache

1. Copy `build/web` to your web server:
```bash
scp -r build/web/* user@server:/var/www/jprime-pwa/
```

2. Configure your web server to serve the files

3. Make sure to serve over HTTPS (required for PWA)

### Option 3: Deploy to Your Current Location

If you want to add it to your existing jprime.io website:

```bash
# Copy to wherever your static files are served
cp -r build/web/* /path/to/jprime-io-static-files/app/
```

## 📱 PWA Install Prompt Features

### What Users Will See

1. **Automatic Popup** (after 3 seconds):
   - Beautiful purple gradient banner at the bottom
   - Message: "📱 Install jPrime app for quick access!"
   - "Install" button
   - Close button (X)

2. **Install Process**:
   - User clicks "Install"
   - Browser shows native install dialog
   - User confirms
   - App installed to home screen/desktop

3. **Smart Behavior**:
   - If user closes the prompt, it won't show again (uses localStorage)
   - Works on Chrome, Edge, Safari (iOS 16.4+)
   - Only shows on HTTPS sites

### Testing the Install Prompt

1. **Desktop Chrome/Edge**:
   - Open your PWA URL
   - Wait 3 seconds for the popup
   - Click "Install"
   - App appears in Applications folder

2. **Mobile (Android)**:
   - Open in Chrome
   - Popup appears after 3 seconds
   - Click "Install"
   - App added to home screen

3. **Mobile (iOS Safari)**:
   - iOS doesn't support `beforeinstallprompt` event
   - Users need to manually tap Share → Add to Home Screen
   - Your manifest.json will style the app correctly

## 🌐 Adding to Your Website

### Include in Your Main Website

Add this to your main jprime.io index page:

```html
<!-- In your <head> -->
<link rel="manifest" href="/pwa/manifest.json">
<meta name="theme-color" content="#6B46C1">

<!-- In your <body>, add a link/button -->
<a href="/pwa/" class="pwa-link">
  📱 Try our mobile app
</a>
```

### Or Create a Separate Route

In your Spring Boot controller:

```java
@GetMapping("/app")
public String redirectToApp() {
    return "redirect:/pwa/";
}
```

## 🎯 Integration Script for Your Website

Add this to your jprime.io website to show the install prompt:

```html
<script>
  // Check if PWA is installable
  let deferredPrompt;
  
  window.addEventListener('beforeinstallprompt', (e) => {
    e.preventDefault();
    deferredPrompt = e;
    
    // Show your custom install button
    document.getElementById('install-button').style.display = 'block';
  });
  
  // When user clicks your install button
  document.getElementById('install-button').addEventListener('click', async () => {
    if (deferredPrompt) {
      deferredPrompt.prompt();
      const { outcome } = await deferredPrompt.userChoice;
      deferredPrompt = null;
    }
  });
</script>
```
